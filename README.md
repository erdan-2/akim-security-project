# 🛡️ Ақпараттық Қауіпсіздік — Инциденттерді Тіркеу Жүйесі

**Система учёта инцидентов информационной безопасности**  
Жалағаш ауданы әкімдігі / Акимат Жалагашского района

---

## 📋 Жоба туралы / О проекте

Бұл жоба Жалағаш ауданы әкімдігінің ақпараттық қауіпсіздік бөліміне арналған инциденттерді тіркеу және бақылау жүйесі.

Данный проект — система регистрации и отслеживания инцидентов информационной безопасности для акимата Жалагашского района.

---

## ⚙️ Мүмкіндіктер / Возможности

- ✅ Инциденттерді тіркеу (вирус, фишинг, рұқсатсыз кіру және т.б.)
- ✅ Статус өзгерту: Жаңа → Жұмыста → Шешілді
- ✅ Маңыздылық деңгейі: Жоғары / Орташа / Төмен
- ✅ Бөлім бойынша фильтрация
- ✅ Жергілікті сақтау (localStorage)
- ✅ Нақты уақыт сағаты
- ✅ Статистика панелі
